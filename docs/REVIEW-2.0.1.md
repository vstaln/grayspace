# OrcSpace 2.0.1 — review

Проверены запуск приложения, Canvas/Code, меню, настройки, сохранение и
восстановление сессий, работа CLI и IPC, ввод, прокрутка, размеры терминалов,
вложения и Windows-упаковка.

## Исправлено

- Текст вывода больше не переключает тип агента на Codex. Упоминание `codex`
  внутри Claude или другого CLI раньше могло менять сочетание вставки картинки.
- Тип CLI определяется по имени исполняемого файла, а не подстроке в полном пути.
- Повторный рендер не затирает распознанный CLI значением `custom`.
- При недоступном системном пути виртуального файла сохраняются его исходные байты.
- Кнопка Account получила стабильное доступное имя.
- UI-тесты ждут окончания заставки, изолируют тестовое окно от рабочего стола
  и проверяют тройное изменение размеров, ранее пропускавшееся в Electron.

## Проверки

- TypeScript: main, renderer и E2E.
- 429 модульных/интеграционных тестов; проверка безопасности релизного архива.
- 31 обычный UI-сценарий прошёл с учётом исправлений и точечных повторных запусков.
- Матрица девяти типов CLI: реальные PTY с контролируемой тестовой программой,
  Unicode, ввод, раскрытие/восстановление панели, переходы Canvas/Code и вставка
  изображения. Это проверяет OrcSpace, а не все версии сторонних AI-программ.
- Реальный Claude Code: перетаскивание картинки без отправки запроса модели.
- На готовой сборке 2.0.1 повторно прошли все три проверки вложений: матрица CLI,
  перетаскивание настоящего файла с пробелами/кириллицей и картинка в Claude Code
  после ввода слова `codex`. Запуск сборки, CLI и контрольный API также прошли.
- `npm audit --omit=dev`: известных уязвимостей не найдено.

## Границы проверки

Нельзя гарантировать отсутствие всех ошибок. Авторизованные сессии каждого
провайдера, сторонние пользовательские сочетания клавиш и WSL/SSH не проверены.
Отдельный HiDPI-тест пропущен в обычном профиле. Полная переустановка поверх
пользовательских данных не выполнялась; релиз запускается с отдельным профилем.
Установщик собран из текущего рабочего дерева, без цифровой подписи издателя.

Защита ASAR и байткод основного процесса сохранены. Они затрудняют анализ,
но не делают установленное приложение недоступным для реверс-инжиниринга.
