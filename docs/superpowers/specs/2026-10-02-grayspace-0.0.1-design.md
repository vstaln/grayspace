# Slate 0.0.1 — Full Native Rebuild (Option B)

## Classification
Architectural (new subsystem: rgpui + wry replaces Electron + eframe). Approved: user chose B, "do whats best". Wayland-separate-window accepted for 0.0.1.

## Goal
One Rust binary (`slate`), pure Rust/GPUI, zero Electron/Chromium/Node in final binary. 5 widgets (staged scope): terminal, planner, files, browser, orchestration.

## What stays untouched
- `native/slate-app/src/engine.rs` — TerminalManager/ControlServer, journal `preserve_order+float_roundtrip`, `indexmap` order.
- `planner.rs`, `planner_document.rs`, `journal_log.rs`, `orchestration.rs`, `ipc.rs` (socket paths, SLATE_* env), `terminal_protocol.rs`.
- Spike proof: `/home/vstaln/wv-spike/src/main.rs` (349), `/tmp/webview-element.rs` (912, PR #54433), `/tmp/webview-example.rs`.

## What changes
1. **Vendor webview**: `/tmp/webview-element.rs` → `native/slate-app/src/webview.rs`, `crate::` → `rgpui::`. `is_wayland()` via env (rgpui has no `guess_compositor`). Keep: 400x300 fallback, >1px guard, Logical bounds (wry scales), per-id LAST_BOUNDS create-once/move-later, gtk-init on glib-loop child thread, Xcb→Xlib shim.
2. **Deps**: add `rgpui 1.3`, `rgpui-platform x11`, `wry 0.57`, `gtk 0.18`, `raw-window-handle 0.6`. Remove `rodio` (alsa, no sudo; music-player out of scope) + `image` (screenshot only). Remove `eframe/egui` once rgpui views land; keep both during transition.
3. **UI**: replace `ui.rs` (1723) eframe + egui paint in `canvas 516`/`terminal_screen 1005`/`files_panel 227`/`plan_panel 609`/`theme`/`code_layout` with rgpui views. Terminal via `portable-pty`+`vt100`/`vte` (already deps). Markdown natively (no HTML). Links open externally.
4. **Delete Electron**: `src/main`, `src/renderer`, `src/preload`, `e2e`, electron scripts.
5. **Rebrand for 0.0.1**: `package.json` name `slate`, version `0.0.1`, productName `Slate`, appId `com.slate.app`, homepage `vstaln/Slate`, publish owner/repo `vstaln/Slate`, `SLATE_VERSION` `0.0.1`, window title `Slate`.

## Wayland
X11-inline via `build_as_child`. Wayland = separate GTK window (wry limitation, why #54433 never merged). Accept for 0.0.1. Defer #61945 overlay.

- `cargo check -p slate-app --lib` (no alsa after rodio removal)
- `cargo test -p slate-app --lib`
- `node scripts/check-version.mjs` (0.0.1 consistent)
- Spike `run.log`: `WV #1 created (X11 child)`, PAINT 1099x700.
