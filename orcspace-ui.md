# OrcSpace UI

## Настройки

Экран настроек должен выглядеть как цельная компактная панель поверх canvas. Используется только существующая палитра OrcSpace: `Base`, `Surface`, `Elevated`, `Raised`, `Line`, белый основной текст и серые вторичные тексты. Новые цвета, градиенты и декоративные акценты не добавлять.

### Структура

- Модальное окно: ширина `820px`, максимальная высота `calc(100vh - 40px)`, фон `Elevated`, радиус `radiusPanel` (`12px`), обводка `Line`.
- Внешние отступы: `24px` сверху/снизу и `28px` слева/справа.
- Слева — навигация шириной `160px`; справа — прокручиваемое содержимое.
- В шапке справа — только кнопка закрытия с hit-area не меньше `32px`.
- На узких окнах навигация становится горизонтальным scrollable-tab bar; содержимое не выходит за границы окна.

### Навигация

Порядок пунктов обязателен:

1. **Account** — первым и активным при открытии настроек.
2. **Appearance**.

Активный пункт использует `Raised` и тонкую обводку `Line`. Неактивные пункты используют прозрачный фон. Hover — `Raised`, focus-visible — внешняя обводка `Line`. Текст неактивных пунктов — secondary, активного — белый.

### Account

- Заголовок: `Account`.
- Подзаголовок объясняет назначение раздела одной короткой строкой.
- Профиль пользователя оформлен карточкой `Surface` с именем, почтой и статусом подключения.
- Действия `Manage account`, `Switch account` и `Sign out` выровнены по правому краю и не выглядят как одинаковые primary-кнопки.
- Если данных нет, показывать аккуратное empty state с одним действием `Connect account`.

### Appearance

Раздел открывается после Account и содержит следующие блоки:

1. **Theme** — карточки `Dark` и `Photo` в одной строке на широком экране и в столбик на узком. Активная карточка имеет фон `Raised`, обводку `Line` и текстовый бейдж `Active`.
2. **Terminal shell** — два radio-card варианта `Command Prompt (CMD)` и `PowerShell`. Состояние выбора понятно по фону, обводке и radio-indicator; не полагаться только на цвет.
3. **Right-click menu** — список checkbox-опций с равной высотой строк, достаточным расстоянием между label и description и сохранением текущего состояния.

### Визуальные правила

- Фон canvas: `Base`; базовая панель настроек: `Elevated`; вложенные карточки: `Surface`; hover/selected: `Raised`; разделители и focus outline: `Line`.
- Не использовать новые цвета, цветные градиенты, разноцветные тени или отдельные акцентные оттенки.
- Основной текст — `#FFFFFF`; secondary — `#B9B9BE`; faint — `#A9A9B0`.
- Заголовок страницы: `20px`, weight `600`; заголовки секций: `11px`, uppercase, letter-spacing `0.08em`.
- Текст должен иметь контраст не ниже AA. Интерактивные элементы — минимальная высота `36px`.
- Состояния `hover`, `active`, `focus-visible`, `disabled` и `error` должны быть определены явно и не менять layout.

### Поведение без багов

- При открытии всегда выбирается первый существующий раздел — `Account`; активный пункт навигации и содержимое должны быть синхронизированы.
- Настройки сохраняются после изменения без сброса scroll-позиции и без повторного монтирования всей модалки.
- Закрытие работает по `X` и `Escape`; клики внутри модалки не закрывают её.
- Переключение разделов не меняет высоту окна скачком, если это не требуется размером содержимого.
- Все controls доступны с клавиатуры, имеют корректные `label`, `aria-checked`/`aria-pressed` и видимый `focus-visible`.
- `prefers-reduced-motion` отключает анимации переходов и blur-эффекты.

## Общая палитра

| Роль | Цвет | Использование |
| --- | --- | --- |
| Base | `#080808` | Canvas и основной фон приложения |
| Surface | `#121212` | Sidebar, rail, вложенные панели |
| Elevated | `#181818` | Модалки и контейнеры верхнего уровня |
| Raised | `#1F1F1F` | Hover, active и выбранные элементы |
| Line | `#2A2A2E` | Обводки, разделители и focus outline |
| Text | `#FFFFFF` | Основной текст |
| Secondary | `#B9B9BE` | Вторичный текст |
| Faint | `#A9A9B0` | Вспомогательные подписи |

## Скругления

Источник геометрии — `src/renderer/src/ui/tokens.ts`:

| Токен | Значение | Применение |
| --- | --- | --- |
| `radiusBar` | `0` | Краевые панели и TitleBar |
| `radiusPill` | `999px` | Переключатели и компактные controls |
| `radiusPanel` | `12px` | Модалки, панели, карточки и виджеты |
